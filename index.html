Reporte técnico

¿Por qué pedimos tu ubicación?

Necesitamos tu ubicación aproximada para adjuntar las coordenadas al reporte técnico y calcular la sucursal más cercana. Solo se lee una vez, no se rastrea tu movimiento y no sale de tu dispositivo.

A continuación tu navegador mostrará su propio cuadro de permiso.

Plan B · Selecciona tu zona

¿Cómo reactivar el permiso?

  • Chrome (Android / PC): toca el ícono 🔒 junto a la URL → Permisos → Ubicación → Permitir.
  • Safari (iPhone): Ajustes → Privacidad y seguridad → Localización → Sitios web de Safari → Preguntar.
  • PWA instalada en iPhone: Ajustes → [nombre de la app] → Ubicación.
